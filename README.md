# TweakSync

## Description

TweakSync is a VS Code extension designed to help front-end developers and web designers update webpage elements and styles in real-time. It allows for seamless integration with your web development workflow, enabling you to make styling changes from within VS Code without switching to your browser.

## Features

- Real-time editing of HTML and CSS files.
- Live preview of changes.
- Integration with Chrome for immediate updates.

## Usage

1. Click on the TweakSync icon in the activity bar to open the panel.
2. Use the provided controls to add, update, or remove files.
3. Monitor real-time changes and updates in your web development environment.
